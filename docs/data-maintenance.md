# アゲテナ データ保守（2026-09-28 / v1.3.13）

## 通常の動作

- 日本時間8:17〜18:17に毎時、既存のGitHub Actionsで50法務局の公式情報を再取得・公開する。
- 取得時は局ごとに件数・庁数・日付の前後関係を検証。局単位の読取りが失敗した場合、不完全な結果を現在掲載分として採用しない。
- 公開後に50局の取得失敗、公開件数0、更新時刻、14日以上古い掲載日付、日付逆転、公開JSONとハッシュの一致を検査する。異常を検出するとActionsを失敗として記録する。
- 平日12:47・18:47には別ワークフロー `data-health.yml` でも公開データを監査。3時間超の更新停止なら、更新処理が走っていないことを確認して既存の更新ワークフローを起動する。
- AI/APIは呼ばない。定期監査のAIトークン消費は0。費用・実行時間はGitHub Actionsの通常の利用条件に従う。
- 異常はActionsのログとSummaryに出す。通知先を新設しない。通知の受信は利用者のGitHub通知設定による。

GitHubのスケジュールは厳密な時刻保証がなく、監査側も遅延する可能性がある。画面にも独立してデータの古さ・局別取得失敗を表示する。全セルの正しさを保証するものではなく、局側の表形式変更で解釈できない場合はエラーにして保守する。
